화면 설계서 메이커screenshot-docs URL 모드 · 주식회사 리모

URL 하나로 화면 설계서를 만듭니다. 여기서 탐색 범위를 정하면 로컬 수집기(Playwright) 실행 명령이 만들어집니다. 수집 결과(screens.json + 스크린샷)는 ② 탭에서 사람이 검토하고 설계서로 내보냅니다.

탐색 설정

탐색 범위
이 경로와 하위 경로만 수집합니다. URL을 바꾸면 자동으로 채워집니다.
보조 입력 · 로그인 영역
수집기는 비밀번호를 입력하지 않습니다. 로그인 상태 파일은 사용자가 직접 준비합니다.

실행 명령

왼쪽에서 설정을 확인하고 「실행 명령 만들기」를 누르세요.

          

            
            
          

          
    
            
  1. 이 저장소를 받아 npm install, npx playwright install chromium (최초 1회)
    2. 
            
  2. 위 명령 실행 → output/에 screens.json, screenshots/*.png, design-doc.html 생성
    3. 
            
  3. ② 탭에서 두 파일을 올려 기능 설명을 검토·수정하고 설계서로 내보내기
    4. 
          

          
수집기는 <a href> 이동만 합니다. 폼 제출·결제·삭제 버튼은 누르지 않고, 실패한 페이지는 URL과 사유를 미수집 목록에 남깁니다.

        

        
브라우저는 보안 정책(CORS)상 다른 사이트 화면을 직접 캡처할 수 없어, 수집은 로컬 수집기가 맡습니다. 이 웹은 수집 설정과 사람의 검토를 맡습니다.

      

    

  


  
  

    
사람이 판단할 지점은 자동 생성된 기능 설명이 실제 화면 의도와 맞는지다. 화면마다 설명을 고치고 「검토 완료」를 표시한 뒤 설계서로 내보냅니다.
